# Commodore BBSes on the internet

Commodore 64/128 bulletin boards you can call over telnet with the emulator's user-port modem
(Modem ▸ Phone Book, or `ATDT host:port` in a terminal program). Most of them send PETSCII, so use
a PETSCII terminal (the bundled one, CCGMS, Novaterm…).

Sources: [The Oasis BBS Commodore listing](https://theoasisbbs.com/commodore-bbs-listing/),
[Telnet BBS Guide](https://www.telnetbbsguide.com/), [8-Bit Boyz](https://8bitboyz.com/bbs-listing/bbs_category/commodore/).
"Answered" = the port accepted a connection when the list was made (2026-11-22).
